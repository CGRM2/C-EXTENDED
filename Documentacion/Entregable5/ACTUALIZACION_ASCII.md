# Textos de programacion en ASCII

La version actual utiliza ASCII en el codigo fuente, comentarios, mensajes de interfaz, manual TXT y pruebas manuales. No se cambiaron las reglas del lenguaje. La prueba Unicode interna conserva su entrada mediante escapes C# para mantener ASCII en el archivo fuente.

La prueba unica usa el identificador anio en su bloque P04. La matriz PDF conserva el caso Unicode original de la verificacion automatica. El JSON actualizado conserva esa entrada mediante escapes Unicode.

Se recompilo Release y se ejecutaron nuevamente las tres baterias: 76 comprobaciones lexicas, 125 de sintaxis e integracion y 22 casos finales, todos aprobados. El ejecutable del paquete corresponde a esta compilacion.

Los PDF y diapositivas conservan las tildes correctas del texto academico. El cambio se aplica a los archivos de programacion y a las entradas manuales.
