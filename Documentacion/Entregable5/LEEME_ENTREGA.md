# Entrega final de C-Extended

1. Extraer el ZIP completo.
2. Abrir Memoria_Final_C_Extended.pdf: integra antecedentes, especificacion, diseno, arquitectura, pruebas y ambos manuales.
3. Consultar Matriz_Pruebas_Entregable5.pdf: entrada, salida esperada, obtenida y resultado de 22 casos.
4. Abrir Presentacion_Final_C_Extended.pptx: 18 diapositivas principales y 3 de apoyo. Las notas contienen tiempos y explicaciones adicionales.
5. Ejecutar Aplicacion/C-Extended.exe en Windows con .NET Framework 4.8.
6. Para probar manualmente, copiar un bloque de Prueba_Unica_C_Extended.txt al editor. Cargar todo el TXT no equivale a ejecutar los 22 casos aislados.

Codigo contiene los fuentes. Evidencias contiene matriz_resultados.json, informes consolidados y resultados de las regresiones.
