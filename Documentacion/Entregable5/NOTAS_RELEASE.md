# Entregable 5 de C-Extended

Aplicacion C# Windows Forms con reconocimiento lexico manual y analisis sintactico simplificado.

El paquete adjunto incluye:

- Memoria final de 20 paginas con antecedentes de los cinco entregables, manual tecnico y manual de usuario.
- Matriz de 22 casos y evidencia completa de resultados.
- Presentacion de 21 diapositivas, con 18 de exposicion y 3 de apoyo para preguntas.
- Archivo de pruebas manuales unico, ejecutable compilado y codigo fuente.

Validacion local de la version ASCII: 22 casos finales, 76 comprobaciones lexicas y 125 de sintaxis e integracion aprobadas. La publicacion compila de nuevo el mismo codigo en Windows antes de crear el paquete.

Extraer el ZIP completo y abrir Aplicacion/C-Extended.exe. Se requiere Windows con .NET Framework 4.8. No se necesita Visual Studio para ejecutar el binario.

Las pruebas manuales se realizan copiando un bloque del TXT a la vez. Cargar el archivo completo incluye errores lexicos deliberados y deja pendiente la sintaxis. La prueba en el equipo de la exposicion y la sustentacion presencial corresponden al grupo.
